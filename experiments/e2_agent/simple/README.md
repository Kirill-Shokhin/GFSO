# E2 `simple` subset — interaction-sparse everyday DECOMPOSITION

> Experimenter-side. **Status: SCAFFOLD — tasks pending.** Subject agents never read this or `references/`.
> **Decomposition only, no implementation** (implementation/self-delegation = E3).

## Purpose
`complex/` tasks are interaction-dense and do not saturate in one pass (single-pass A≈B; divergence is the
iterative arm). `simple/` tasks are everyday and **saturate in one pass**, so the differentiator would be
**in-the-moment structure** — whether the decomposition surfaces the **series of small, often-silently-skipped
links** a rushed agent drops (a count of skipped significant links = the signal, not a single trap). This is
the regime where a single-pass GFSO difference could show, if anywhere.

## Why no implementation (vs the earlier `build` idea, retired)
Running code measures EXECUTION (executor competence + self-delegation config) = **E3**, not decomposition.
And for **simple** tasks the faithfulness gap is relaxed (Lemma 1): the significant links are **a-priori
assessable** (you needn't run an LRU cache to know "evict-dirty must flush"), so the reference is buildable
and **human-auditable without execution** — same apparatus as `complex`.

## Apparatus
Uses the **shared top-level** apparatus (`../prompt_A_bare.md`, `../prompt_B_gfso.md`, `../prompt_judge.md`,
`../SCORING.md`) — identical to `complex` (both are decomposition). This subset adds only its dataset
(`PLAN.md`, `tasks/`, `references/`).

## Task design (when built)
Small everyday decomposition targets, each with a **series** of significant often-skipped links + 2–3
deliberate ambiguities; reference = the a-priori-assessable significant links (small, auditable). Candidate
themes (decomposed, NOT implemented): LRU+TTL cache · layered config merge · money line-item total ·
next-N billing dates · retry-with-backoff.

**Honest risk:** everyday tasks are the most in-zone for Opus; if a thorough bare agent decomposes them
fully, `simple` ties too — which would point the method's value (if any) at execution (E3), not decomposition.
