How to read the graph
node → its part
a solid arrow runs from a node to one of its parts — the split
producer → its user
a dashed arrow runs from a part to the one that uses its result; that one waits for it to pass (Dep)
pulse
a node at work; filled in the accent when a process of this server runs it
number
how many delivery rounds a node took; in the accent while its last one failed
double-click
a node: frame it with all its parts · the background: the whole graph
How to read the marks
dot
a PASS — in a criterion's row and its history, and on a progress track
cross
a FAIL — the same mark in every view
dotted line under a cross
on a progress track: a FAIL whose record names only what failed — the rest are unknown, so its height (and the count ≤ k) is only an upper bound
ring
a criterion's round with no value: not checked, or not named by that round's FAIL
⊥
no verdict yet — not a third value: V is pass or fail once checked (§2.3)
